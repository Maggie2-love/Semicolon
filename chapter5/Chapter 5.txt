

5.5 — Basic elements of counter-controlled iteration
1. Counter variable —>This keeps track of how many times the loop runs.
2. Initial value —> This is where the counter starts.
3. Condition —> It determines whether the loop should continue.
4. Increment/decrement —> It changes the counter after each repetition.



5.6 — Compare while and for loops

Both while and for are used to repeat statements.

A while loop is commonly used when you do not know exactly how many times the loop will run.

while A for loop is commonly used when you know the number of repetitions.



5.7 — do...while or while?

Use a do...while loop when the body must execute at least once.

A while loop checks the condition before executing.



5.8 — break vs continue

break completely stops the loop.
continue does not end the loop. It only skips the current iteration.

break = leave the loop

continue = skip this round and continue the loop



5.9(a) — Find and correct the error

The code shown is:

while (i = 1; i <= 10, i++)
    System.out.println(i);

This is incorrect because a while statement accepts only one condition inside its parentheses.

The correct version is:

int i = 1;

while (i <= 10) {
    System.out.println(i);
    i++;
}


5.9 (b)

case value < 0:

A switch cannot use a condition like value < 0 as a case.

For this problem, if...else if is better:

if (value < 0) {
    System.out.println("Negative");
}
else if (value == 0) {
    System.out.println("Zero");
}
